# Titanic-Survival-Prediction
# 🚢 Titanic Survival Prediction

A beginner-friendly Machine Learning project that predicts whether a passenger survived the Titanic disaster using Python and Logistic Regression.

---

## 📌 Overview

The Titanic Survival Prediction project uses the famous Titanic dataset from Kaggle to build a binary classification model. The project demonstrates the complete machine learning workflow, including data preprocessing, visualization, model training, evaluation, and prediction.

---

## 🎯 Objective

Predict whether a passenger survived the Titanic disaster based on passenger information such as age, gender, passenger class, fare, and family details.

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📂 Dataset

- Titanic - Machine Learning from Disaster (Kaggle)

Files:
- `train.csv`
- `test.csv`

---

## 📊 Features Used

- Passenger Class (Pclass)
- Gender (Sex)
- Age
- Fare
- Siblings/Spouse (SibSp)
- Parents/Children (Parch)
- Embarked

**Target Variable:**
- Survived (0 = No, 1 = Yes)

---

## ⚙️ Project Workflow

1. Import required libraries
2. Load the dataset
3. Explore and understand the data
4. Handle missing values
5. Encode categorical features
6. Select important features
7. Split data into training and testing sets
8. Train Logistic Regression model
9. Evaluate model performance
10. Predict passenger survival

---

## 📈 Model Used

**Logistic Regression**

It is a simple and effective algorithm for binary classification problems like Titanic Survival Prediction.
